# Contributing

Issues and pull requests are welcome for reproducibility fixes,
documentation improvements, dependency updates, and workflow maintenance.

Before opening a pull request:

1. Explain the analysis or reproducibility problem being addressed.
2. Keep raw, controlled-access, and locally licensed source data out of the
   repository.
3. Document any changed input schema, package requirement, or output.
4. Preserve the citation to the associated iScience article.

Please do not submit patient-level data, private manuscripts, or files copied
from an IHME or other third-party source in a pull request.
